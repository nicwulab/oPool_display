Step 2: Sequence Segments Iteration

Input Parameters
Source: This file comes from Step 1 (Extract) output - typically named *_output.csv
Example: TableS1_full_output.csv
Number of random sequences to generate
Optional: CSV file with negative control data (can be same as input file)
Description

This step generates random codon sequences for each amino acid to reduce similarity among nucleotide sequences. Each antibody is truncated into 8 segments for increased diversity.

Step 3: CD-HIT Clustering

CD-HIT Parameters

This step groups similar sequences using CD-HIT based on sequence similarity. It takes the output from Step 2 and clusters segments based on similarities.

Note: This step may take a long time depending on the dataset size. Check the cd-hit.log file for progress.
Run CD-HIT
Results will be stored in the 'cdhit' directory.

Step 4: Result Selection & Reassembly

Selection Parameters
Number of sequences per group
Total number of groups to create
Number of negative control sequences per group
Description

This step selects one sequence from each CD-HIT cluster and reassembles antibodies. It creates groups of sequences for assembly libraries.

Final Library Generation

This final step processes multiple files to truncate antibodies into segments based on the selected overlap regions and adds replication primers for synthesis.

Prerequisites: Requires completed Steps 1-5 with corresponding files in:

  • ui_results/ - FASTA sequence files

Pipeline Info

This pipeline constructs antibody libraries by:

  • Filtering and completing antibody sequences
  • Generating random codon variants
  • Clustering similar sequences
  • Selecting unique overlap regions
  • Creating final libraries with primers
