This step generates random codon sequences for each amino acid to reduce similarity among nucleotide sequences. Each antibody is truncated into 8 segments for increased diversity.

Step 3: CD-HIT Clustering

CD-HIT Parameters

This step groups similar sequences using CD-HIT based on sequence similarity. It takes the output from Step 2 and clusters segments based on similarities.

Similarity thresholds for clustering (0.6 to 0.85 in 0.05 increments by default)
Note: This step may take a long time depending on the dataset size. Real-time progress will be shown in the output window.
Run CD-HIT
Results will be stored in ui_results/step3/.
